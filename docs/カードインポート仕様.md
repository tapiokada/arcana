# カードインポート仕様（arcana-set/1）

外部で作成したオリジナルカード（**画像＋能力データ**）を Arcana Duel に取り込むためのインタフェース仕様です。
カードは「**セット**」単位で配布・インポートします。

---

## 1. 配布形式（フォルダ構成）

```
MySet/                  ← 任意のフォルダ名
├─ set.json             ← セット定義（必須・UTF-8）
└─ images/              ← 画像（set.json からの相対パスで参照）
   ├─ MY-001.png
   ├─ MY-002.jpg
   └─ ...
```

- インポート方法
  1. アプリの「設定・カードインポート」→ **フォルダ選択** で `MySet` フォルダを選ぶ（推奨）
  2. または **ファイル選択** で `set.json` と画像を複数選択（画像は `images/<ファイル名>` として扱われます）
  3. または `data/sets/<セットコード>/` にフォルダを直接コピーしてアプリを再起動
- 取り込み時に検証が行われ、エラーがあればカードID・項目名つきで一覧表示されます（1件でもエラーがあれば取り込みません）。
- 同じセットコードで再インポートすると **上書き更新** になります（所持枚数・デッキは保持）。

## 2. 画像仕様

| 項目 | 仕様 |
|---|---|
| 形式 | PNG / JPEG / WebP / GIF / SVG |
| サイズ上限 | 1ファイル 2MB |
| `imageType: "art"`（既定） | **イラストのみ**。アプリがカード枠・名前・コスト・テキスト・P/T を描画します。推奨 600×440px（横長 約4:3） |
| `imageType: "full"` | **カード全面画像**（枠・文字込みで外部作成）。推奨 630×880px（63:88）。P/T 等の変動値はアプリが重ねて表示します |
| 埋め込み | `"image": "data:image/png;base64,..."` の Data URL も可（小さなセット向け） |
| 省略時 | 色に応じたグラデーションで表示（警告扱い、取り込みは可） |

> 対戦時、自分のデッキに含まれるカードの定義と画像は対戦相手へ自動送信されます。相手がそのセットを持っていなくても対戦可能です。

## 3. set.json の構造

```json
{
  "format": "arcana-set/1",
  "set": {
    "code": "MY1",
    "name": "はじまりの魔導書",
    "version": "1.0.0",
    "author": "作者名",
    "description": "説明文（任意）",
    "starter": false
  },
  "cards": [ /* カード定義の配列 */ ]
}
```

| キー | 型 | 必須 | 説明 |
|---|---|---|---|
| `format` | string | ✔ | 固定値 `"arcana-set/1"`。将来の仕様変更時に版を上げる |
| `set.code` | string | ✔ | セットコード。英数字・`_`・`-` で2〜16文字。全セットで一意 |
| `set.name` | string | ✔ | セット名（表示用） |
| `set.version` | string |  | セットの版 |
| `set.author` | string |  | 作者 |
| `set.description` | string |  | 説明 |
| `set.starter` | boolean |  | `true` の場合、初回にコモン4枚・アンコモン2枚・レア1枚ずつ配布し、スターターデッキを作成 |

## 4. カード定義

```json
{
  "id": "MY1-001",
  "name": "紅蓮竜ヴォルカリオン",
  "cost": "{4}{R}{R}",
  "types": ["Creature"],
  "supertypes": ["Legendary"],
  "subtypes": ["Dragon"],
  "power": 5,
  "toughness": 5,
  "keywords": ["flying"],
  "abilities": [
    { "type": "triggered", "trigger": "etb",
      "effects": [ { "action": "damage", "amount": 3, "target": "any" } ] }
  ],
  "text": "飛行\nこれが戦場に出たとき、クリーチャー1体かプレイヤー1人を対象とする。これはそれに3点のダメージを与える。",
  "flavor": "空が赤く染まるとき、竜は目覚める。",
  "rarity": "mythic",
  "image": "images/MY1-001.png",
  "imageType": "art",
  "artist": "絵師名"
}
```

| キー | 型 | 必須 | 説明 |
|---|---|---|---|
| `id` | string | ✔ | カードID。**全セットで一意**（`セットコード-連番` を推奨） |
| `name` | string | ✔ | カード名（同名カードはデッキに4枚まで。レジェンド・ルールも名前で判定） |
| `cost` | string |  | マナ・コスト。`{数字}` 不特定、`{W}{U}{B}{R}{G}` 色、`{C}` 無色。土地は省略 |
| `types` | string[] | ✔ | `Land` `Creature` `Instant` `Sorcery` `Enchantment` `Artifact`（複数可：例 `["Artifact","Creature"]`） |
| `supertypes` | string[] |  | `Basic`（基本土地：枚数制限なし・無料） / `Legendary`（レジェンド・ルール適用） |
| `subtypes` | string[] |  | 自由記述。特別扱い: `Plains/Island/Swamp/Mountain/Forest`（対応色マナ能力を自動付与）、`Aura`、`Equipment` |
| `power` / `toughness` | number | クリーチャーは✔ | パワー/タフネス |
| `keywords` | string[] |  | キーワード能力（§5） |
| `abilities` | object[] |  | 能力（§6） |
| `enchant` | target |  | オーラのエンチャント対象（既定 `"creature"`） |
| `colors` | string[] |  | 色を明示する場合（既定はコストから自動算出） |
| `text` | string |  | ルール文章（表示用）。**省略時は abilities から自動生成** |
| `flavor` | string |  | フレーバーテキスト |
| `rarity` | string |  | `common` `uncommon` `rare` `mythic` `basic`（既定 common）。パック封入率・価格に影響 |
| `price` | number |  | ショップ価格の上書き（既定: C=20, U=60, R=200, M=500 G。売却は40%） |
| `image` | string |  | 画像の相対パスまたは Data URL |
| `imageType` | string |  | `art`（既定） / `full` |
| `artist` | string |  | イラストレーター |

> **重要**: `text` は表示専用です。ゲーム上の動作は **`keywords` と `abilities` だけ** で決まります。

## 5. キーワード能力

| 値 | 名称 | 値 | 名称 |
|---|---|---|---|
| `flying` | 飛行 | `vigilance` | 警戒 |
| `reach` | 到達 | `haste` | 速攻 |
| `first_strike` | 先制攻撃 | `defender` | 防衛 |
| `double_strike` | 二段攻撃 | `menace` | 威迫 |
| `trample` | トランプル | `hexproof` | 呪禁 |
| `deathtouch` | 接死 | `indestructible` | 破壊不能 |
| `lifelink` | 絆魂 | `flash` | 瞬速 |

## 6. 能力（abilities）

`type` によって5種類あります。

### 6.1 `spell` — 呪文能力（インスタント／ソーサリー）
解決時に `effects` を順に実行します。
```json
{ "type": "spell", "effects": [ { "action": "damage", "amount": 3, "target": "any" } ] }
```

### 6.2 `triggered` — 誘発型能力
```json
{ "type": "triggered", "trigger": "attacks", "effects": [ { "action": "pump", "power": 1 } ] }
```

| trigger | 誘発条件 |
|---|---|
| `etb` | これが戦場に出たとき |
| `dies` | これが死亡したとき（戦場から墓地へ） |
| `attacks` | これが攻撃したとき |
| `upkeep` | あなたのアップキープの開始時 |
| `end_step` | あなたの終了ステップの開始時 |
| `creature_etb_you_control` | 他のクリーチャーがあなたのコントロール下で戦場に出るたび |
| `landfall` | 土地があなたのコントロール下で戦場に出るたび |
| `cast_spell` | あなたが呪文を唱えるたび（`"filter": "noncreature"` でクリーチャー以外のみ） |
| `deals_combat_damage_to_player` | これがプレイヤーに戦闘ダメージを与えるたび |

対象を取る誘発型能力は、スタックに置く際にコントローラーが対象を選びます（候補1つなら自動、候補なしなら取り除かれる）。

### 6.3 `activated` — 起動型能力
```json
{ "type": "activated", "cost": "{2},{T}", "speed": "sorcery", "effects": [ { "action": "draw" } ] }
```
- `cost` の書式: マナ記号の並び ＋ カンマ区切りで追加コスト
  - `{T}` タップ（クリーチャーは召喚酔い中は不可） / `sacrifice` これを生け贄 / `life:N` ライフをN点支払う
  - 例: `"{1}{B},{T}"`, `"{T},sacrifice"`, `"{B},life:2"`
- `speed`: `"sorcery"` を指定するとソーサリー・タイミングのみ（装備など）。既定はインスタント・タイミング

### 6.4 `static` — 常在型能力（P/T・キーワードの修整）
```json
{ "type": "static", "affects": "other_creatures_you_control", "modify": { "power": 1, "toughness": 1, "keywords": ["vigilance"] } }
```
| affects | 対象 |
|---|---|
| `self` | これ自身 |
| `attached` | これがつけられているクリーチャー（**オーラ・装備品で使用**） |
| `creatures_you_control` / `other_creatures_you_control` | あなたの（他の）クリーチャー |
| `creatures_opponents_control` | 対戦相手のクリーチャー（負の値で弱体化） |
| `all_creatures` | 全てのクリーチャー |

### 6.5 `mana` — マナ能力
```json
{ "type": "mana", "produce": ["G"] }      // {T}: {G} を加える
{ "type": "mana", "produce": ["W","U"] }  // {T}: {W}か{U}
{ "type": "mana", "produce": ["any"] }    // {T}: 好きな色1色
```
コストは常に `{T}`。基本土地タイプを持つ土地は自動付与されるため記述不要。

## 7. 効果（effects）

各効果は `action` と、効果を及ぼす相手を **`target`（対象を取る）** または **`subject`（対象を取らない）** で指定します。

### 7.1 action 一覧

| action | パラメータ | 内容 |
|---|---|---|
| `damage` | `amount` | ダメージを与える（発生源が接死・絆魂を持てば適用） |
| `draw` | `amount` | カードを引く（既定 subject: `you`） |
| `gain_life` / `lose_life` | `amount` | ライフを得る／失う |
| `destroy` | – | 破壊（破壊不能は無効） |
| `exile` | – | 追放 |
| `bounce` | – | オーナーの手札に戻す |
| `tap` / `untap` | – | タップ／アンタップ |
| `pump` | `power` `toughness` `keywords` | ターン終了時まで修整・キーワード付与（既定 subject: `self`） |
| `counters` | `amount` | +1/+1カウンターを置く（負数で -1/-1） |
| `token` | `amount`, `token:{name,power,toughness,colors,subtypes,keywords}` | クリーチャー・トークン生成 |
| `counter` | – | 対象の呪文を打ち消す（target は `spell` 系） |
| `discard` | `amount`, `random` | カードを捨てる（既定は本人が選択、`random:true` で無作為） |
| `mill` | `amount` | ライブラリーの上から墓地へ |
| `add_mana` | `color`, `amount` | マナを加える |
| `return_from_graveyard` | `to`: `hand`/`battlefield` | 墓地のカードを戻す |
| `attach` | – | これ（装備品）を対象のクリーチャーにつける |
| `sacrifice` | – | 生け贄に捧げる |

### 7.2 target（対象を取る）

文字列、またはフィルタ付きオブジェクトで指定します。
```json
"target": "creature"
"target": { "kind": "creature", "filter": { "maxPower": 2 } }
```

| kind | 対象 |
|---|---|
| `any` | クリーチャーかプレイヤー |
| `player` / `opponent` | プレイヤー／対戦相手 |
| `creature` / `creature_you_control` / `creature_opponent_controls` | クリーチャー |
| `permanent` / `nonland_permanent` / `noncreature_permanent` | パーマネント |
| `artifact` / `enchantment` / `artifact_or_enchantment` / `land` | 各タイプ |
| `spell` / `creature_spell` / `noncreature_spell` | スタック上の呪文 |
| `creature_card_in_your_graveyard` / `card_in_your_graveyard` | あなたの墓地のカード |

filter: `maxPower` `minPower` `maxManaValue` `tapped`(bool) `color` `notColor` `keyword` `attacking`(bool)

**同じ対象を再利用**: `"target": "$0"` と書くと、1つ目の対象（0番）を参照します。
```json
"effects": [
  { "action": "damage", "amount": 2, "target": "creature" },
  { "action": "tap", "target": "$0" }
]
```

### 7.3 subject（対象を取らない）

`you` `self` `each_opponent` `each_player` `all_creatures` `creatures_you_control` `other_creatures_you_control` `creatures_opponents_control` `attached`

## 8. 記述例

**インスタント（火力）**
```json
{ "id": "MY1-010", "name": "雷撃の矢", "cost": "{R}", "types": ["Instant"], "rarity": "common",
  "abilities": [{ "type": "spell", "effects": [{ "action": "damage", "amount": 3, "target": "any" }] }] }
```
**オーラ**
```json
{ "id": "MY1-011", "name": "守護の加護", "cost": "{W}", "types": ["Enchantment"], "subtypes": ["Aura"], "enchant": "creature",
  "abilities": [{ "type": "static", "affects": "attached", "modify": { "power": 1, "toughness": 2, "keywords": ["vigilance"] } }] }
```
**装備品**
```json
{ "id": "MY1-012", "name": "勇者の長剣", "cost": "{2}", "types": ["Artifact"], "subtypes": ["Equipment"],
  "abilities": [
    { "type": "static", "affects": "attached", "modify": { "power": 2, "toughness": 1 } },
    { "type": "activated", "cost": "{2}", "speed": "sorcery", "effects": [{ "action": "attach", "target": "creature_you_control" }] } ] }
```
**トークン生成クリーチャー**
```json
{ "id": "MY1-013", "name": "ゴブリンの扇動者", "cost": "{2}{R}", "types": ["Creature"], "subtypes": ["Goblin"], "power": 2, "toughness": 2,
  "abilities": [{ "type": "triggered", "trigger": "etb", "effects": [{ "action": "token",
    "token": { "name": "ゴブリン", "power": 1, "toughness": 1, "colors": ["R"], "keywords": ["haste"] } }] }] }
```
**基本土地**
```json
{ "id": "MY1-L1", "name": "山", "types": ["Land"], "supertypes": ["Basic"], "subtypes": ["Mountain"], "rarity": "basic", "image": "images/mountain.png" }
```

同梱の `sets/starter/set.json`（49枚）が全機能の実例です。`tools/build-starter.js` はそれを生成するスクリプトです。

## 9. 検証ルール（取り込み時）

- `format` が `arcana-set/1` であること / `set.code`・`set.name` 必須
- カード `id` の重複なし（セット内・既存セット間とも）
- `types` `supertypes` `keywords` `action` `target` `subject` `trigger` `affects` が本仕様の値であること
- `cost` が正しいマナ記号のみで構成されること
- クリーチャーに数値の `power` / `toughness` があること
- 参照された画像ファイルが存在し、2MB以下・対応形式であること
- パスに `..` や絶対パスを含まないこと

## 10. 未対応の要素（今後の拡張候補）

プレインズウォーカー、X コスト、キッカー等の追加コスト、モード選択、置換効果（「代わりに」）、
ダメージ割り振り順の手動指定、複数対象（「最大2体」等）、条件付き効果（「〜なら」）、
コピー、コントロール奪取、プロテクション、レイヤー（タイプ・色の変更）。
拡張時は `format` の版を `arcana-set/2` 等に上げ、旧版は引き続き読み込めるようにします。
