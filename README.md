# Arcana Duel

友人とインターネット越しに対戦できる、MTG風トレーディングカードゲーム。
オリジナルのカード（画像＋能力データ）をインポートして遊べます。

## 必要なもの
- [Node.js](https://nodejs.org/) 18 以上（Windows / macOS / Linux）

## 起動
- Windows: `start.bat` をダブルクリック
- macOS / Linux: `./start.sh`
- 手動: `npm install` → `npm start`

ブラウザで `http://localhost:3000/` が開きます（`--port 3001` でポート変更、`--no-open` で自動起動しない）。

## 友人と対戦するには
対戦の仲介をする **中継サーバー** が1つ必要です。
1. どちらか1人（またはVPS）が `start-relay.bat`（`npm run relay`）を起動し、TCP **7700** を開放
2. 両者が「設定」で中継サーバーURLを `ws://<サーバーのIPアドレス>:7700` に設定
3. 片方が「対戦 → ルームを作成」、表示されたコードをもう片方が「ルームに参加」で入力

アプリを `npm start -- --relay` で起動すると中継サーバーも同時に立ち上がります。

## 収録セット
| セット | 枚数 | 入手方法 | 特徴 |
|---|---|---|---|
| 第1弾「アルカナの夜明け」(AD1) | 49 | 初回起動時にスターターとして配布 | 基本ルール一式 |
| 第2弾「遺跡の目覚め」(AD2) | 61 | 「カード入手・売却」でパック購入 | 新ルール「占術」「共鳴」、遺物の欠片トークン、2色土地 |

## オリジナルカードのインポート
`set.json` と画像フォルダを用意し、「設定・カードインポート」から読み込みます。
形式は [docs/カードインポート仕様.md](docs/カードインポート仕様.md) を参照してください。
